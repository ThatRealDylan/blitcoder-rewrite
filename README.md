Q: How did you come up with the name for BR?

A: A common misconception is that i named it BR because the meaning of 'blit', bit block transfer which means to move/copy pixel data rapidly. But that is actually not the reason. The reason is because once, i was talking to my friend and teaching him about computers, then we got talking into Monitors, and when i tried to explain bits, while having native english, I mispronounced it as 'blits', the name stuck with me and history is history.
